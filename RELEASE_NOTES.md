# GamesTrack 0.2.11

## Русский

- Исправлен экран входа Android: кнопки Google, Discord и электронной почты теперь отображаются стабильно даже при медленной загрузке Clerk.
- Добавлено понятное состояние разрешения уведомлений и быстрый переход в системные настройки.
- Нажатие на уведомление теперь открывает связанную игру.
- Ссылки `gamestrack.top/games/...` и публичные топы открываются приложением напрямую.
- Добавлена автоматическая диагностика сбоев для ускорения исправлений.

> Если установлена версия 0.2.8 или новее, APK обновляется поверх без удаления приложения.

## English

- Fixed Android sign-in: Google, Discord, and email actions now stay visible even while Clerk is still loading.
- Added a clear notification-permission status and a shortcut to Android settings.
- Tapping a notification now opens the related game.
- `gamestrack.top/games/...` and shared top links now open directly in the app.
- Added automatic crash diagnostics to make fixes faster.

> If version 0.2.8 or newer is installed, this APK updates it in place without uninstalling the app.
